# Вязаный глобус Babushka Exchange

На сайте модуль подключён к странице `/about/`. Отдельный просмотр на синем фоне доступен по адресу `/assets/about/knit/index.html`. Для работы в браузере все ресурсы глобуса раздаются с сайта.

## Локальная разработка

Из каталога `globe` выполните `npm ci` и `npm run dev`. Команда `npm run texture` воспроизводит карты из исходных PNG и атласа суши. Она нужна при изменении вязки. Команда `npm run build` собирает модуль в `dist/` и копирует готовые файлы в `../assets/about/knit/` для существующего сервера и статической публикации.

## Подключение к калькулятору

Для уже смонтированного глобуса на странице «О нас» достаточно вызвать:

```js
import {viewer} from '/assets/about/knit/viewer.js';
viewer.focusCity('Дубай');
```

Для отдельного контейнера подключите CSS из сборки и создайте экземпляр:

```js
import {initKnitGlobe} from '/assets/about/knit/viewer.js';

const globe = initKnitGlobe(container, {
  autoRotate: true,
  onCityClick(city) { console.log(city.name); }
});
globe.focusCity('Алматы');
// При удалении компонента
globe.destroy();
```

Для своего контейнера задайте размер и позиционирование (position: relative). Атрибут `data-knit-globe` зарезервирован для автоматического подключения первого глобуса на странице. При ручной инициализации дайте контейнеру класс `knit-container`. Метод `focusCity` возвращает false для неизвестного города и после уничтожения экземпляра. Вызов до первого появления запоминает выбранный город. При нескольких вызовах камера переходит к последнему выбранному городу.

## Настройка

- В `data/cities.js` хранятся города с координатами и маршруты. Каждая запись маршрута содержит порядок, названия начального и конечного города и высоту дуги в радиусах сферы.
- В `tools/make-knit-texture.mjs` задаются красители, правило для материков, размер петли и seed. Земная поверхность собрана из `stitch.png`, скрутка маршрутов — из центральной части `yarn.png`. Размеры карт для настольных и мобильных устройств составляют 4096×2048 и 2048×1024.
- Вращение доступно мышью, пальцем и стрелками клавиатуры. Наведение или касание открывает название города. Ограничение ручного наклона составляет 60–120°. Программное наведение может центрировать город за пределами этого диапазона.
- На экранах уже 768 px одновременно видны до пяти нитей. Системная настройка уменьшенного движения отключает автовращение, нити и кольца. После потери WebGL-контекста показывается исходный PNG. Инициализация и отрисовка следуют за видимостью контейнера и вкладки.
