# Разработка Babushka Exchange

Используйте Node.js 24 со встроенным SQLite. Из корня проекта запустите `node server/app.mjs` и откройте `http://127.0.0.1:8080/`. Калькулятор доступен по адресу `/#exchange`, админка — по адресу `/admin/`. На чистой копии командой `node server/manage-access.mjs` можно создать отдельную учётную запись для разработки.

Из корня запускайте тесты командой `node --test tests/*.test.*`. Они проверяют расчёты, правила обмена, обработку заявок и защиту доступа.

## Где вносить изменения

- Главная страница находится в `index.html`. Интерфейс калькулятора использует `desk.js` и `desk.css`, логика расчётов — `exchange-core.js`.
- В `server/` находится сервер приложения, в `admin/` — интерфейс менеджера. Базовые курсы тестовые. Сервер сохраняет рассчитанные заявки в SQLite. Доставка в Telegram ожидает подключения.
- Страница «О нас» находится в `about/index.html`. Исходники интерактивного глобуса и инструкция по его сборке находятся в `globe/`. После изменения глобуса выполните в этой папке `npm ci` и `npm run build`. Сборка обновляет файлы сайта в `assets/about/knit/`.

## Данные и окружение

Для новой среды разработки используйте отдельную базу и ключ. Локальная база находится в `.local/`, ключ шифрования по умолчанию — в `~/.config/babushka-exchange/requests.key`. Храните их вне Git. Подробности по настройке, резервному копированию и запуску за HTTPS-прокси приведены в `README.md`.
