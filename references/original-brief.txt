Задача: сделать статичный прототип hero-блока для сайта криптообменника Babushka Exchange. Главное — кинематографичное появление сцены: сначала темно, лампа мигает, включается свет, бабушка гладит кота. Только HTML + CSS + vanilla JS, без фреймворков и сборщиков.

## Файлы (уже лежат в ./assets)
- scene-dark.png — тёмный кадр (свет выключен), 2688×1520
- scene-lit.png — тот же кадр при включённом свете, 2688×1520
- intro.mp4 — видео 1920×1088, ~5 с: из темноты лампа мигает (≈0.8 с вспышка, ≈1.2 с гаснет, ≈1.7 с снова), к ≈3 с комната полностью освещена. Последний кадр совпадает с scene-lit.png
- loop.mp4 — видео 1920×1088, ~6 с, бесшовный цикл: бабушка гладит кота. Первый и последний кадр совпадают с scene-lit.png
- logo.png — белый логотип (косынка), прозрачный фон

## Шаг 0. Оптимизация ассетов (если есть ffmpeg)
Создай ./assets/opt и сделай:
- intro.mp4 и loop.mp4 → H.264, CRF 26, preset veryfast, без аудио, -movflags +faststart, ширина 1920 и копия шириной 1280 (для мобильных/медленных сетей): intro-1920.mp4, intro-1280.mp4, loop-1920.mp4, loop-1280.mp4
- scene-dark.png и scene-lit.png → webp, качество 80, ширина 1920: scene-dark.webp, scene-lit.webp
Если ffmpeg/cwebp нет — используй исходники и напиши мне команды для оптимизации в README.

## Структура
index.html, styles.css, main.js, README.md.

## Слои hero (fullscreen, 100svh, overflow hidden)
Снизу вверх, все слои position:absolute; inset:0; object-fit:cover; object-position: 50% 45%:
1. <img class="poster poster--dark"> — scene-dark (виден сразу, грузится первым, fetchpriority="high")
2. <img class="poster poster--lit"> — scene-lit (opacity 0, для фолбэков)
3. <video id="intro" muted playsinline preload="auto"> — intro
4. <video id="loop" muted playsinline loop preload="auto"> — loop (скрыт, opacity 0)
5. .hero__shade — градиенты для читаемости текста: radial-gradient из левого верхнего угла (rgba(8,6,4,.75) → transparent ~55%) + linear-gradient снизу (rgba(8,6,4,.6) → transparent 35%)
6. .hero__ui — интерфейс (шапка, заголовок, кнопка)
Выбор источника видео: через <source media> или JS — 1280-версия при ширине экрана < 1280 или navigator.connection.saveData.

## Сценарий появления (main.js)
1. На старте видны только poster--dark и чёрный экран; весь UI скрыт (opacity 0).
2. Как только intro может играть (canplay) — intro.play(). Если за 3 с intro не стал готов, или play() отклонён (iOS Low Power Mode, автоплей запрещён) → ФОЛБЭК (см. ниже).
3. Во время intro по событию timeupdate:
   - при currentTime ≥ 2.6 с — показать UI (класс .is-revealed на hero): шапка, заголовок, подзаголовок, кнопка появляются каскадом (opacity 0→1, translateY 16px→0, 600 мс, ease-out, задержки 0 / 150 / 300 / 450 мс).
   - при currentTime ≥ duration − 0.12 с — loop.currentTime = 0; loop.play(); сразу сделать loop видимым (opacity 1, без перехода), intro скрыть. Переход должен быть незаметен, т.к. кадры совпадают. loop заранее вызвать load() при старте страницы, чтобы он был в буфере.
4. Дальше крутится loop.
5. Повторный заход в рамках сессии: sessionStorage 'bx_intro_seen' (обернуть в try/catch). Если флаг есть — пропустить intro: сразу poster--lit + loop, UI виден сразу.
6. prefers-reduced-motion: reduce — не проигрывать видео вообще: показать poster--lit, UI виден сразу, без анимаций.
7. Пауза loop, когда вкладка скрыта (visibilitychange) и когда hero вне экрана (IntersectionObserver), возобновление при возврате.

## ФОЛБЭК без видео (CSS-мигание лампы)
Если видео недоступно — сымитировать то же самое на картинках: poster--lit поверх poster--dark с анимацией opacity по ключевым кадрам ~3 с: 0%→0, 18%→0.85, 24%→0.05, 34%→0.9, 40%→0.2, 55%→0.7, 100%→1 (steps-эффект мигания, затем плавно на полную). Затем показать UI так же каскадом.

## Адаптив
- ≤ 900px: меню прячется в бургер (простое выпадающее меню), «Оставить заявку» остаётся иконкой или скрывается в меню; H1 сверху (top 14vh), кнопка «Обменять» снизу во всю ширину минус 24px отступы (bottom 32px); object-position: 50% 40% (бабушка с котом в центре кадра).
- Проверить 1440×900, 1920×1080, 390×844, 768×1024.

## Доступность и качество
- Видео: aria-hidden="true", без звука, без controls. H1 и кнопка — настоящий HTML-текст.
- Никаких ошибок в консоли; не ломается при отключённом JS (тогда видны poster--lit и UI: по умолчанию в CSS без JS UI видим, скрытие добавляет класс .js на <html>).
- Lighthouse: LCP — тёмный постер, CLS = 0.

## README.md
Как запустить локально (python3 -m http.server 8080 или npx serve), что где лежит, где поменять тайминги (константы в начале main.js: REVEAL_AT = 2.6, SWAP_BEFORE_END = 0.12, INTRO_TIMEOUT = 3000).

## Критерии приёмки
1. При первом заходе: темнота → лампа мигает → свет → бабушка гладит кота; UI появляется каскадом на ~2.6 с.
2. Переход intro → loop не виден глазом (нет мигания/чёрного кадра).
3. Цикл бесконечный, без рывка на стыке (если рывок заметен — сделать перекрёстное затухание 300 мс между двумя экземплярами loop-видео, чередуя их).
4. Повторный заход в сессии — сразу свет и цикл.
5. iPhone Safari в режиме энергосбережения и reduced-motion — показывается светлая сцена с UI, ничего не ломается.
