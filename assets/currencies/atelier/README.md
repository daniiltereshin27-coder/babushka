# Babushka currency icons

21 AI-generated illustrations in the approved USD style: green enamel, aged brass and ivory relief. Generated with ChatGPT image generation.

PNG: original transparent masters. WebP: 256px web exports with alpha, quality 90. Filenames map directly to keys in desk.js. USDC uses ERC20; four USDT icons identify TRC20, ERC20, SOL and TON. These are custom illustrations, not official brand asset files.
